# SoulNest — Mental Well-being Portal

SoulNest is a mental well-being web application built with Next.js, React, and TypeScript. It provides user authentication pages and an AI-powered well-being companion for supportive conversations.

## Features
- User signup and login
- AI-powered well-being chat
- Simple, user-friendly interface

## Tech Stack
- Next.js
- React
- TypeScript
- OpenAI API

## Getting Started

```bash
git clone https://github.com/shrushti2186/SoulNest.git
cd SoulNest
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment Variables

Create a `.env.local` file:

```env
OPENAI_API_KEY=your_api_key
OPENAI_MODEL=gpt-4o-mini
```
